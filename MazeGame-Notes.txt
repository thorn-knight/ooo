Process to convert animations to new maze game in Krita.
    1. Start with spritesheet from old maze game resources folder, open it in krita.
    2. In krita, file -> new. 32x42 dimensions.
    3. Rectangle select the image from the spritesheet and copy it.
    4. In new file, paste or do ctrl + alt + v to paste at cursor (useful if it gets cut off on paste). Save the new file (as PNG). Rectangle select it and move it if needed.
    5. Close and re-open the file. Pick a color to be the background and use the fill tool (paint bucket thing) to fill it everywhere there's background.
    6. Select the similar color selection tool and click on the background color. Press delete key, this should remove all the background.
    7. Close and re-open the file. Image -> scale image to new size. Do dimensions 64x84 and save it.
    8. Rinse and repeat for each image in the spritesheet.
    9. Once done use free texture packer to re-pack everything into a texture png + json file. IMPORTANT - select JSON (array) as the format for melon.
